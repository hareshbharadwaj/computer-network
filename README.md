# Computer Network Lab — Cisco Packet Tracer Files

A collection of network simulation exercises built with **Cisco Packet Tracer**, covering topologies, routing, DHCP, subnetting, and core protocols. Useful for revision, demo purposes, or as a starting point for networking coursework.

## 📁 Repository Structure

| Folder | Contents |
|---|---|
| `topologies/` | Bus, star, ring, tree, mesh, and hybrid topology setups |
| `routing-and-dhcp/` | Static & dynamic routing, DHCP, and Class C subnetting labs |
| `protocols-simulation/` | CSMA, TCP/UDP, and data-link layer (ARP) traffic simulations |
| `labs/` | General lab and project files |

## 🛠 Requirements

- [Cisco Packet Tracer](https://www.netacad.com/courses/packet-tracer) (free; 8.x recommended — all files use the standard `.pkt` format)

## ▶️ Usage

1. Open Cisco Packet Tracer.
2. Go to **File → Open** and select any `.pkt` file from the folders above.
3. Explore the devices, run simulations (**Simulation Panel**), and modify the setup as needed.
